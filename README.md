# idea

An MVP idea-workbench for turning rough ideas into clean business-style artifacts.

This repo is optimized for the first week of use:

- fast outlines
- presentation-first output
- simple text-first source files
- minimal structure that is easy to review

## Start here

- Repo behavior and working style: [AGENTS.md](C:\Users\ISSUser\git\idea\AGENTS.md)
- Shell and local/cloud usage guide: [docs/codex_workflow.md](C:\Users\ISSUser\git\idea\docs\codex_workflow.md)
- Windows shell guidance: [docs/shell-usage.md](C:\Users\ISSUser\git\idea\docs\shell-usage.md)

## Repo folders

- `ideas/` for rough notes and raw inputs
- `tasks/` for structured task files
- `presentations/` for slide sources
- `documents/` for markdown docs
- `spreadsheets/` for csv or tabular specs
- `diagrams/` for mermaid or simple diagrams
- `templates/` for reusable starting points
- `exports/` for generated deliverables when needed

## MVP rule

Keep the repo small, text-first, and practical. Create exports only when needed.
